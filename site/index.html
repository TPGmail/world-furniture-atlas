    Định vị chính xác bằng Google Maps

    Dữ liệu GPS xấp xỉ của phiên bản trước đã bị xóa khỏi bản đồ. Để định vị theo địa chỉ thực, cần Google Maps API key có giới hạn website và quyền Maps JavaScript API + Geocoding API.

    Google Maps Platform có thể tính phí. Không đặt API key không giới hạn lên GitHub. Bản đồ chỉ hiển thị kết quả được Google định vị chính xác tới địa chỉ (ROOFTOP).
